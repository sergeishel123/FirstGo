
Days to New Year

## Назначение приложения

Приложение на Go, которое рассчитывает количество календарных дней, оставшихся от заданной даты до ближайшего следующего Нового года (1 января следующего календарного года). Подключен HTTP-сервер

## Требования для запуска

- Go


## Способ сборки

go build -o days-to-new-year 

## Способ запуска
go run.

Сервер запускается на порту 8080: http://localhost:8080.

## Способ запуска тестов

go test -v ./... 

## Предоставляемый HTTP API
GET - запрос http://localhost:8080/SergeyAndDays?date=

Возвращает количество дней до Нового года.

## Формат входных параметров
Параметры передаются в query-строке:

Параметр: date. Формат	YYYY-MM-DD

Дата, относительно которой выполняется расчёт. Если дата не указана то используется текущая дата.

## Формат ответа
Ответ — JSON.

Успех (HTTP 200):

json
{
  "Количество дней до Нового Года": 365,
  "date": "2024-01-01"
}

Ошибка (HTTP 400):

json
{
  "Ошибка": "Неправильный формат даты, используй формат YYYY-MM-DD"
}
