# Days to New Year

## Назначение приложения

Приложение на Go, которое рассчитывает количество календарных дней, оставшихся от заданной даты до ближайшего следующего Нового года (1 января следующего календарного года). Расчёт учитывает високосные годы. Функция расчёта доступна как через HTTP API, так и напрямую в коде.

## Требования для запуска

- Go 1.23 или новее.
- Внешние зависимости отсутствуют (используется только стандартная библиотека Go).

## Способ сборки

```bash
go build -o days-to-new-year .

## Способ запуска
bash
go run.
или (после сборки):
bash
./days-to-new-year
Сервер запускается на порту 8080: http://localhost:8080.

##Способ запуска тестов
bash
go test ./...
Предоставляемый HTTP API
text
GET /SergeyAndDays
Возвращает количество дней до Нового года.

##Формат входных параметров
Параметры передаются в query-строке:

Параметр	Обязательный	Формат	Описание
date	Нет	YYYY-MM-DD	Дата, относительно которой выполняется расчёт. Если не указана — используется текущая дата.

## Формат ответа
Ответ — JSON.

Успех (HTTP 200):

json
{
  "Количество дней до Нового Года": 365,
  "date": "2024-01-01"
}
Ошибка (HTTP 400):

json
{
  "Ошибка": "Неправильный формат даты, используй формат YYYY-MM-DD"
}
